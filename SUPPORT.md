### 问问题 / 讨论

- 用法疑问、设计讨论、求助：[GitHub Discussions](https://github.com/sheep-programmer/AIForge/discussions)（待开启）
- 真 bug：[新建 issue](https://github.com/sheep-programmer/AIForge/issues/new/choose)

### 报告安全漏洞

**请不要**在公开 issue 提安全问题。请走私下渠道：

- GitHub Security Advisory：https://github.com/sheep-programmer/AIForge/security/advisories/new
- 或者发邮件给维护者（见 [SECURITY.md](SECURITY.md)）

我们会在 7 天内回复。

### 商业支持 / SLA

AIForge 是 Apache 2.0 开源项目，没有官方商业支持。如果你需要：

- 部署咨询
- 私有化定制
- 优先 bug 响应

可以在 Discussion 区开一个 thread，社区里有热心的贡献者愿意接咨询。

### 响应预期

| 渠道 | 预期响应 |
|------|----------|
| 安全漏洞 | 7 天内 |
| 严重 bug（数据丢失、服务不可用） | 工作日 3 天内 |
| 普通 bug | 1-2 周 |
| 功能请求 / 用法咨询 | best-effort，无保证 |
| PR review | 1 周内 |

### Check the docs first

90% of common questions are answered in [docs/](docs/):

- **Getting started**: [docs/getting-started.en.md](docs/getting-started.en.md)
- **Architecture / API contract**: [docs/architecture.en.md](docs/architecture.en.md)

### Ask questions / discuss

- Usage questions, design discussions, help wanted → [GitHub Discussions](https://github.com/sheep-programmer/AIForge/discussions) (to be enabled)
- Actual bugs → [open an issue](https://github.com/sheep-programmer/AIForge/issues/new/choose)

### Reporting security issues

**Do not** file public issues for security problems. Use a private channel:

- GitHub Security Advisory: https://github.com/sheep-programmer/AIForge/security/advisories/new
- Or email the maintainers (see [SECURITY.md](SECURITY.md))

You'll get a response within 7 days.

### Commercial support / SLA

AIForge is an Apache 2.0 open-source project; there is no official commercial support. If you need:

- Deployment consulting
- Private customization
- Priority bug response

Open a thread in Discussions — community contributors often pick up consulting work there.

### Response expectations

| Channel | SLA |
|---|---|
| Security report | within 7 days |
| Critical bug (data loss, service down) | within 3 business days |
| Normal bug | 1-2 weeks |
| Feature request / usage question | best-effort, no guarantee |
| PR review | within 1 week |
